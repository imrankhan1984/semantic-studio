# Bundled vocabularies: sources and licences

Semantic Studio ships these files so that an ontology importing them resolves
with no network connection (`external-access.md` Stage 2, decision D-068).
Each file is unmodified: byte for byte what its source URL served on
2026-09-27, pinned by SHA-256 in `manifest.json`. They are used read-only and
are never edited or re-published as Semantic Studio's own.
